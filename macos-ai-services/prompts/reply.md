Task — Reply: write the reply the user will send to the message in the selected text.
- The selected text is a message the user received; it may include earlier quoted messages. Reply to the most recent message, from the user to its sender.
- Answer every question and respond to every request in it. Where the answer depends on something only the user knows (availability, a decision, a figure), write a placeholder in square brackets in the language of the reply, for example [confirmar a data] or [confirm the date].
- Match the formality of the incoming message and use the greeting and closing customary in that language (for European Portuguese, for example "Caro …," / "Cara …," and "Com os melhores cumprimentos,"). Use the sender's name if it appears in the message; do not invent names. End with the closing line, without a name after it.
- Keep it as short as the content allows. Do not repeat or quote the original message and do not add a subject line.
